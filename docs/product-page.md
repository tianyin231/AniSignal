# 产品介绍页

[产品定位](../README.md) · [功能指南](features.md) · [部署指南](deployment.md)

## 入口与范围

独立页面为 **`/intro`**，现有 `/` 信息工作台保持不变。工作台页脚新增“产品介绍”入口。合并后还需构建和部署 Web，线上地址才会出现新页面；提交代码不等于已部署。

页面以“**让重要的变化，找到你。**”为主文案，依次展示多源采集、事件证据、商品进展、个人关注与独立监控、AI 辅助、管理与来源健康，以及网站、邮件和 AstrBot / QQ 群送达。当前采集的作品与商品不是产品的固定适用范围。

## 交互与文案约定

| 区域 | 实现 | 功能含义 |
| --- | --- | --- |
| 首屏纵深叠卡 | CSS `perspective` / `preserve-3d`，收拢、展开、点选前移、关闭归队 | 将来源与事件视图分层表达；不暗示所有内容都会自动归并。 |
| 指针与滚动反馈 | 精细指针下的轻量视差，IntersectionObserver 渐入，阅读进度 | 辅助空间感与阅读；不劫持滚动，不持续运行动画循环。 |
| 关键词演示 | 三类机制切换、输入筛选、预设词、清空和空结果状态 | 区分站点采集、个人关注及独立 B 站监控。 |
| 送达演示 | QQ 群 / 邮件 / 站内切换、示例关键词、消息预览、短时连线和入场动效 | QQ 群通过 AstrBot 接入；邮件与站内阅读不被弱化。 |
| 功能卡与常见问题 | 轻量悬停反馈、原生 `details` | 保留其他产品属性、能力前提与实际边界。 |

**演示不是后台操作。** 示例在静态模板中明确标注；输入只在当前页面内筛选，不读写用户存储、不请求采集接口、不新建监控、不调用 AI，也不向 QQ 群或邮箱发送消息。消息预览使用“未实际发送”的反馈，不能改成“发送成功”。离开页面即丢弃演示状态。

关键词含义保持一致：管理员目标决定公共采集范围；用户关注词筛选站内已有内容；独立监控使用单独存储；群关键词限定该会话的消息范围，不自动扩大采集范围。定时全站早报与按需关键词邮件也不是同一种通知。

真实入口继续使用现有路由：`/`、`/contents`、`/events`、`/products`、`/account`、`/sources`、`/about` 和 `/admin/bot`。机器人设置仍由原管理认证保护，不添加 QQ 登录、测试群号或虚构的入群入口。

## 文件

- [`web/app/pages/intro.vue`](../web/app/pages/intro.vue)：独立 Nuxt 页面（`layout: false`）、SEO 元信息与服务端可读模板。
- [`web/app/assets/css/product.css`](../web/app/assets/css/product.css)：`as-` 命名空间样式，独立浅色品牌页面，不改用户的工作台主题偏好。
- [`web/app/utils/product-experience.ts`](../web/app/utils/product-experience.ts)：DOM 渐进增强；由 Vue 挂载，卸载时清理监听、观察器、计时器和动画帧。
- [`web/app/components/AppFooter.vue`](../web/app/components/AppFooter.vue)：仅新增产品介绍链接。

不增加 npm 依赖；不使用外部字体、重型 3D 引擎或付费动效库。图形为原生 SVG / CSS，卡片文字可选择和读取，不是截图。

## 可访问性与降级

支持键盘展开、卡片左右切换、Home / End、Esc 退出查看与焦点归还；两组页签支持方向键、Home / End 和正确的 ARIA 关联。输入有标签与结果提示，FAQ 使用原生语义。

遵循 `prefers-reduced-motion`，并提供手动暂停动效。触屏不启用悬停视差；减少动效不禁用筛选和切换。禁用 JavaScript 时仍能阅读产品介绍和访问真实入口。渐入使用渐进增强，缺少 IntersectionObserver 时不会隐藏内容。
