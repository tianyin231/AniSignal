# 更新日志

本文件记录 **AniSignal 情报助手（DeepSeek Harness 插件）** 的版本变更。源码在 [AniSignal 主仓库](https://github.com/tianyin231/AniSignal) 的 `integrations/dsh_plugin_anisignal` 中维护，发版后同步至本仓库。

## v1.15.0 (2026-11-24)

- **官方公告修订提醒（抓暗改）**：在 DSH 插件设置面板新增「官方公告修订提醒（抓暗改）」开关（`revisions_enabled`，默认关闭，遵守免打扰），监测到官方原文实质改字、改时间或换图时即时推送，自动跳过风控抓漏。
- **新增 `revisions` 查询工具**：开放对话查询工具新增「官方修订」（`revisions`），支持通过 `anisignal_query` 检索近期官方暗改记录，并支持调用 `anisignal_expand` 展开修订详情。
- **聊天修改订阅支持**：`anisignal_subscription` 新增 `action="revisions"`（`on`/`off`），开启聊天改订阅后可口述开关官方修订提醒。
- **模板与选源补齐**：通知模板新增 `revisions: "官方修订"` 类型标签；补充小黑盒关键词与账号监控的选源展示标签。

## v1.14.10 (2026-11-21)

- 设置页支持勾选账号自建监控与公共监控（含小黑盒账号监控），并同步展示来源标签。

## v1.14.9 (2026-11-15)

- 插件设置页与详情页支持自动检查更新（每 6 小时）、手动检查与一键更新，安装目标锁定至检查到的提交 SHA。

## v1.14.8 (2026-11-15)

- 修复模型工具 JSON Schema 注册校验，确保全部工具定义通过严格校验。

## v1.14.7 (2026-11-14)

- 首个独立发布版本：支持腾讯官方 QQ Bot 与 OneBot v11 / NapCat 双通道推送、SVG→PNG 每日早报情报卡及完整查询/订阅/提醒工具集。
